# Beach Club

Sistema web para um beach club com aulas de beach tênis e vôlei de praia: agenda de aulas e turmas,
alunos e planos, financeiro e locação avulsa de quadras, com áreas separadas para administração/recepção,
professores e alunos.

Stack: Next.js (App Router, TypeScript) + Supabase (schema `beach`) + Vercel.

## App web

Detalhes de execução local, regras de acesso por papel e deploy na Vercel em [docs/app-nextjs.md](docs/app-nextjs.md).

```bash
cp .env.example .env.local
npm install
npm run dev
```
